Define a ranvar corresponding to the poisson probability distribution with the parameter 5, and display it as a scalar

# ANSWER

```envision
r = poisson(5)
show scalar "Poisson probabilistic distribution" a1b3 with
  r

// Alternatively, it can also be done without defining any variable :
show scalar "Poisson probabilistic distribution" a1b3 with poisson(5)
```
